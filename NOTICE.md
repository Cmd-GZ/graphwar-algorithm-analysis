# NOTICE — origin of the code in this repository

## 1. Nothing from the game is redistributed

This repository contains **no** Graphwar binaries, extracted assets, string dumps or
decompiler output. `.gitignore` excludes them and `analysis/regen.sh` rebuilds them
from a copy of the game you supply yourself.

Two of those excluded files are also why this matters beyond copyright:
`analysis/lib_strings.txt` and the Ghidra dumps contain the game developer's build
paths (`/home/<name>/.cargo/...`), i.e. personal information.

Everything committed here is:

* original code written during the analysis (`analysis/*.py`, `graphwar_curve.py`),
* plots generated by that code (`docs/*.png`),
* prose (`README.md`, `REPORT.md`, this file).

## 2. `analysis/gw1_model.py` and `analysis/gw1_parser.py` are GPL-3.0 derivatives

Graphwar 1 is licensed **GPL-3.0** (© 2011 Lucas Catabriga Rocha). Those two files are
straight ports of

* `Function.java` — `getRK4()`, `getRK42()`, `setNextValues()`, `processRange()`
* `PolishNotationFunction.java` — the tokenizer, the reorder-to-Polish recursion, the evaluator

and therefore remain **GPL-3.0-or-later**. They carry a header saying so.
They exist only so the GW1 and GW2 samplers can be compared on equal footing

licence. Everything else is the author's own work.

**The repository as a whole is licensed GPL-3.0-or-later** (see `LICENSE`), which keeps it
compatible with those ports. Note that this licence covers *this repository's* contents only
and grants no rights whatsoever over the game itself.

## 3. What this work is / is not

* It is a behavioural study of a program for interoperability and research purposes:
  the goal is to understand and document a numerical algorithm, and the reimplementation
  is written from the observed behaviour plus public GW1 source, not by copying GW2 code.
* It is not a redistribution of the game, and it is not a "crack": no DRM, licence check,
  network protocol or payment code was touched.
* Graphwar, Graphwar II and their assets belong to their author. If the author objects to
  anything here, the affected material will be removed.

## 4. Unofficial project / commercial product

* Graphwar II is sold commercially (Steam) and monetised on Android through optional
  in-app purchases. This repository redistributes **none** of it and does not interact
  with any licensing, purchase, advertising or DRM logic — the analysis is limited to the
  numerical routine that turns a typed function into trajectory points.
* Nothing here is an in-game assistant: no memory reading, no client hooking, no
  automated play. It is an offline calculator plus a written analysis.
* "Graphwar" appears only as a descriptive reference to the subject of the analysis.
  This project is not affiliated with, endorsed by, or sponsored by the game's author.
* If the author requests removal of any material, it will be removed.
